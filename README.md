# <a id="home-page"></a>My Favorite Albums Home

My Favorite Albums is a browser application that analyzes user music tastes over a range of time. 
It covers album data such as year of release, user rating, artist/band, vinyl status, extended play, and live recording. 
By using this data My Favorite Albums can graphically display the information of the user's favorite albums in an organized and intuitive manner.
